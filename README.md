## Pasos para replicar la aplicación:

### 1. Clonar o descargar el repositorio

### 2. Crear y activar el entorno virtual dentro de la carpeta de la aplicación
```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Instalar las librerías necesarias
```bash
pip install -r requirements.txt
```

### 4. Ejecutar la aplicación
```bash
streamlit run Datos_F1.py
```
